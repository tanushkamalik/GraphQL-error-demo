# GraphQL Error Demo

A Node.js project using Express and GraphQL to explore GraphQL API behavior and error handling.

## Technologies Used

- Node.js
- Express.js
- GraphQL
- express-graphql

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

### Run the Project

The project entry point is configured as `index.js` in `package.json`. Once the application code is verified, run:

```bash
node index.js
```

## Purpose

This project is intended to explore GraphQL functionality in a Node.js and Express environment.
